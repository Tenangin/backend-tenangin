Mental Wellness Backend API Documentation

This documentation describes the available API endpoints for the Mental Wellness Backend.

Base URL: http://localhost:3000/api

Authentication

Register (Manual)

POST /api/auth/register

Register a new user with email and password.

{
  "email": "user@example.com",
  "password": "yourpassword"
}

Login (Manual)

POST /api/auth/login

Login user and receive JWT token.

{
  "email": "user@example.com",
  "password": "yourpassword"
}

Profile

Get Profile

GET /api/profile

Get profile data of authenticated user.

Create Profile

POST /api/profile/add

Create profile for authenticated user.

{
  "full_name": "John Doe",
  "place_of_birth": "City",
  "date_of_birth": "1990-01-01",
  "age": 30,
  "gender": "Male",
  "address": "123 Street",
  "about_me": "Short bio"
}

Update Profile

PUT /api/profile/edit

Update profile data for authenticated user.

{
  "full_name": "John Doe",
  "place_of_birth": "City",
  "date_of_birth": "1990-01-01",
  "age": 31,
  "gender": "Male",
  "address": "123 Street",
  "about_me": "Updated bio"
}

Assessment History

Get Assessments

GET /api/assesment

Get all assessment history for authenticated user.

Create Assessment

POST /api/assesment

Create a new assessment record.

{
  "score": 85,
  "condition": "Good",
  "result_text": "Mental condition is good."
}

Journal Entries

Get Journal Entries

GET /api/journal

Get all journal entries for authenticated user.

Create Journal Entry

POST /api/journal/add

Create a new journal entry.

{
  "content": "Today I felt happy and productive.",
  "sentiment": "positive"
}

Clinics

Get Clinics

GET /api/clinics

Get all clinics data. This endpoint does not require authentication.

Google OAuth

Login with Google OAuth is available via /api/auth/google routes.

Get Session Token

After logging in with Google, you can retrieve the session token using Supabase's auth client as follows:

const { data, error } = await supabase.auth.getSession();
if (error) {
  console.error('Error getting session:', error);
} else {
  console.log('Session data:', data);
}
