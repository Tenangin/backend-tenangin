Tenangin Backend API Documentation

This documentation describes the available API endpoints for the Tenangin Backend.

Base URL: https://tenangin-backend.vercel.app/api

Authentication

Register (Manual)

POST /auth/register

Register a new user with email and password.

{
  "email": "user@example.com",
  "password": "yourpassword"
}

Login (Manual)

POST /auth/login

Login user and receive JWT token.

{
  "email": "user@example.com",
  "password": "yourpassword"
}

Google OAuth

GET /auth/google

Login using Google OAuth.

Profile

Get Profile

GET /api/profile

Get profile data of authenticated user.

Create Profile

POST /api/profile/add

Create profile for authenticated user.

{
  "full_name": "John Doe",
  "place_of_birth": "City",
  "date_of_birth": "1990-01-01",
  "age": 30,
  "gender": "Male",
  "address": "123 Street",
  "about_me": "Short bio"
}

Update Profile

PUT /api/profile/edit

Update profile data for authenticated user.

{
  "full_name": "John Doe",
  "place_of_birth": "City",
  "date_of_birth": "1990-01-01",
  "age": 31,
  "gender": "Male",
  "address": "123 Street",
  "about_me": "Updated bio"
}

Assessment History

Get Assessments

GET /api/assessment

Get all assessment history for authenticated user.

Create Assessment

POST /api/assessment

Create a new assessment record.

{
  "score": 85,
  "condition": "Good",
  "result_text": "Mental condition is good."
}

Journal Entries

Get Journal Entries

GET /api/journal

Get all journal entries for authenticated user.

Create Journal Entry

POST /api/journal/add

Create a new journal entry.

{
  "content": "Today I felt happy and productive.",
  "sentiment": "positive"
}

Clinics

Get Clinics

GET /api/clinics

Get all clinics data. This endpoint does not require authentication.

Chatbot Sessions

Create Session

POST /api/chatbot/sessions

Create a new chatbot session.

{
  "summary": "Session summary text",
  "mood_detected": "happy"
}

Get Sessions

GET /api/chatbot/sessions/:id

Get all chatbot sessions for authenticated user.

Get Session Messages

GET /api/chatbot/sessions/:sessionId/messages

Get all messages for a specific chatbot session.

Add Message

POST /api/chatbot/sessions/:sessionId/messages

Add a message to a specific chatbot session.

{
  "sender": "user",
  "message": "Hello, chatbot!"
}

Update Session

PUT /api/chatbot/sessions/edit/:id

Update chatbot sessions for authenticated user by users_id.

{
  "summary": "Updated session summary",
  "mood_detected": "neutral"
}

Delete Session

DELETE /api/chatbot/sessions/:idSession

Delete a chatbot session by its session ID.

Reminders
